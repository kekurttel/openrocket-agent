# Motor: AeroTech M1850 (TFM1850W)

Şartname 4.1.19: **A2 Orta İrtifa ve A4 Uluslararası** kategorilerdeki her takıma
bir (1) adet M1850 tipi AeroTech motor verilir. Motor seçimi takımın elinde
**değildir**.

## Teknik veri (motor eğrisinden)

| Özellik | Değer |
|---|---|
| Tanım | TFM1850W |
| Çap | 75 mm |
| Uzunluk | 935.4 mm |
| Yakıt | 4.103 kg |
| Toplam kütle | **7.010 kg** |
| Atma gecikmesi | 1000 ms |
| Tepe itki | 2411 N |
| Yanma süresi | 6.75 s |
| Ortalama itki | 1115 N |
| Entegre itki (trapezoidal) | ≈ 7524 N·s |
| Özgül itki | ≈ 187 s |

## Motor dosyası

`designs/m1850-teknofest/motors/Teknofest26_M1850_Rev1.eng` — aynı dosya
`~/.openrocket/ThrustCurves/` altına kuruludur, böylece `.ork` dosyaları yeniden
açıldığında motor kaybolmaz (OpenRocket 24.12 `.ork` içine thrust curve **gömmüyor**).
