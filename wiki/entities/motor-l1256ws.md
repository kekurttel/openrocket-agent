# Motor: AeroTech L1256WS (TFL1256WS)

Şartname 4.1.18: **A1 Lise** kategorisindeki her takıma bir (1) adet L1256 tipi
AeroTech motor verilir.

## Teknik veri (motor eğrisinden)

| Özellik | Değer |
|---|---|
| Tanım | TFL1256WS |
| Çap | 75 mm |
| Uzunluk | 530.6 mm |
| Yakıt | 1.905 kg |
| Toplam kütle | 3.905 kg |
| Atma gecikmesi | yok (yok → `EJECTION` = burnout) |
| Tepe itki | 1470 N |
| Yanma süresi | 2.967 s |
| Ortalama itki | 1230 N |
| Entegre itki (trapezoidal) | ≈ 3650 N·s |
| Özgül itki | ≈ 195 s |

Motor dosyası: `~/.openrocket/ThrustCurves/Teknofest26_L1256_Rev1.eng`
(kaynak: `Aerotech_Motorlarına_İlişkin_Teknik_Bilgiler_...zip` içindeki
`Teknofest26_L1256_Rev1.eng`).

## A1 ailesinin karakteri

L1256WS'li 5 örnek tasarımın apogee aralığı **3389–3976 m** (standart koşu),
kalkış kütlesi 11.24–12.02 kg, 0.3 Mach stabilitesi 2.00–2.59 kal. A1 asgari
irtifa 4.000 ft (1219 m) → hepsi geçiyor.

A1'de kurtarma tek paraşütle bütünseldir (4.2.4), bu yüzden örneklerde iki
paraşüt (ana + payload) var.
